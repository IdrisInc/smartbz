# Roadmap

## Done (this iteration)
- User management owner actions: change role from the list, activate/deactivate members, send/resend invite (set-password email), status badges in list and details dialog.
- Deactivated memberships no longer grant access to the business.
- Restaurant support: `restaurant` business sector, restaurant sector configuration (menu categories, metrics, workflows), `restaurant_tables` table with RLS, Restaurant page (floor plan, table CRUD, live status), sidebar entry for restaurant/hospitality businesses.

## Next
- Restaurant orders: link table to an open sale, kitchen order status flow, split/merge bills.
- Menu management view built on products filtered by restaurant categories.
- Email-based invite via edge function (branded invite instead of password-reset link).
